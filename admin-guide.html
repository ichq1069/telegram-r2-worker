1快速上手

从打开后台到完成第一个管理动作，全程不到一分钟。

  1. 访问地址：在浏览器打开 https://<worker域名>/admin，或直接访问 https://telegramup.wo58.cn/admin。
  2. 登录：输入后台 API Key（部署时配置的 API_KEY）。Key 也可以写成 URL 参数 /admin?api_key=xxx 自动登录。
  3. 查看状态：登录后默认进入「概览」，可看到 D1 数据库、R2 存储、Worker 运行与 Webhook 状态。
  4. 日常维护：Tele 群里的文件会自动入库并转存，管理员的日常工作主要是「快速打标」给文件分类、在「共享库」维护对外展示的图片。
导航结构：后台左侧侧栏按 概览 / 文件 / 素材库 / 接口 / Bot 配置 / 系统 六组排列，共 21 个功能标签页。本手册按编号逐一说明。

2级别体系

整个系统的内容权限模型基于「级别对等」，理解它才能正确使用共享库、私密库与密钥。

级别含义谁可访问
pt普通所有密钥（默认级别）
vip会员vip 及以上密钥
svip超级会员svip 及以上密钥
vvip最高级（含私密库）仅 vvip 密钥
级别对等原则：低级别密钥看不到高级别内容。例如 vip 密钥请求公开接口时，只会返回 pt 和 vip 级别的文件，绝不会输出 svip/vvip 内容。
私密库：私密库内容等同 vvip，仅出现在私密库页面，不参与任何公开接口 / 画廊 / 轮播 / Inline 搜图输出。

3概览

系统运行状态的一站式看板，包含四大块。

D1 数据库

文件、共享库、密钥等全部元数据的存储情况：总记录数、各表行数分布。

R2 对象存储

实际文件存储：已用容量、对象数量、按套餐配额的使用比例。若配置了 CF_API_TOKEN（R2 读取权限），这里显示 Cloudflare 官方真实用量；未配置则用本地估算。

Worker 运行

Worker 请求计数、今日处理量、请求趋势（最近 14 天），以及用量预测（基于今日速率线性外推，仅供参考）。

Telegram Webhook

机器人消息接收通道状态。显示 webhook 是否挂载、URL 是否正确、待处理更新数。若显示未挂载，点「修复」按钮自动重新设置 webhook。

提示：文件类型分布与热门群组两块卡片能快速了解内容构成与来源分布。

4用户统计

Telegram 用户维度统计：用户 ID、用户名、昵称、文件数、总大小、最近活跃时间。了解谁在用、贡献了多少内容。

支持查看每个用户的交互行为详情（消息数、使用次数等）。

5Tele 文件

Telegram 群/频道里发过来的原始文件库，是共享库和私密库的内容来源。

传输进度

实时显示正在转存的文件队列、进度条、成功/失败统计。文件消息先秒回 #id 收据，下载上传在后台异步完成。

存储去重

对文件计算 MD5，把内容完全相同的重复文件识别出来。

  • 扫描并清理：重复文件移入回收站（可恢复），R2 对象仍保留。
  • 扫描并彻底删除：直接删除重复文件及其 R2 对象，不可恢复，务必先「查看重复分组」核对。

查重已后台化：定时任务每 5 分钟自动扫描一批，点按钮可立即多扫一批加速，不会超时。

存储压缩（WebP）

把已转存的 JPEG/PNG 图片压缩为 WebP（质量 80，预计省 50-70% 存储）。需要账号启用 Cloudflare Image Resizing，未启用时运行会明确提示。注意 压缩后不可还原原图。回收站中超过 30 天的文件由定时任务自动硬清（含 R2 对象），无需手动。

上传 / 导入

手动给文件库加内容：选择入库级别与标签后，可本地上传（R2）、或粘贴外链 URL 逐行导入（重复自动跳过）。入库后文件参与公开 API 输出（按级别对等过滤）。

TG 直传

通过「用户上传配置」绑定的上传群，直接把文件发送到群里（sendDocument），返回的 file_id 入库为代理记录，不占 R2 存储。需先在「运维 → 用户上传配置」设置绑定群组。

文件管理

网格/列表两种视图，支持按文件名/Caption/标签搜索、按类型 / 导入状态 / 来源筛选。来源包含 tg（Telegram）、manual（手动上传）、代理（TG 直传）等。勾选后可批量操作：

  • 删除选中：移入回收站（可恢复）。
  • 复制直链 / 代理链接 / 双链接：一键复制 R2 直链或 /file/tg/<id> 代理链接。
  • 打标签：批量给文件加标签。
  • 加入共享库：把 Telegram 文件转入共享库（自动带原级别与标签）。
  • 转入私密库：复制到私密库（等同 vvip）。
  • 忽略导入 / 取消忽略：批量导入时跳过或恢复。

6未转存

已入库但转存未完成的记录。

消息先入库（秒回 #id），文件下载/上传异步进行。这里列出所有已入库但未完成的记录：

  • 全部重试：手动重试所有失败/未完成项。
  • 定时任务每 5 分钟也会自动重试 pending / failed 记录。
  • 超过 20MB 且未配置本地 Bot API 的文件会直接失败。

7回收站与孤儿

软删除与存储残留的清理中心。

回收站（软删除，可恢复）

从任何位置删除的文件都会先进回收站。支持「全部恢复」或「清空回收站」。超过 30 天的回收站文件由定时任务自动硬删（含 R2 对象）。

R2 孤儿对象

R2 中存在但 D1 无任何引用的残留对象（通常是删除流程中断造成的）。「扫描孤儿」列出，核对后「清理孤儿」删除，清理不可恢复。

8共享库

对外展示的核心图库，供公开接口 / 画廊 / 轮播 / Inline 搜图使用。支持文件夹组织。

添加图片

支持多种存储源：

存储源说明
本地上传 (R2)图片存入你自己的 R2，无数量限制、永不过期，推荐首选。
Zupimages用挂件上传到 Zupimages 后，粘贴图库页/直链一键抓取导入。
Postimages填入 Postimages API Key，上传到外部图床（免费每月 1000 次）。
外链链接直接粘贴图片 URL 导入，支持预设标签点选、标题。
TG 直传通过上传群发文件，file_id 入库为代理记录，不占 R2 存储。

所有来源都可设置入库级别（默认 pt），标签通用。来源与外链图分开管理。

文件夹管理

共享库支持按文件夹分组组织。可新建文件夹、重命名、删除；图片可移动到指定文件夹。

共享库内容

按标题/标签/来源/启用状态/文件夹筛选。勾选后可批量：打标签、设置级别、转入私密库、批量启用/停用、复制链接、移动文件夹、批量删除。停用的图片不会出现在任何对外输出中。

来源说明：manual = 手动上传/外链导入；tg = 从 Telegram 文件「加入共享库」导入；代理 = TG 直传（不占 R2）。

9私密库

最高级别（vvip）专属内容，严格与公开渠道隔离。

支持与共享库相同的多种存储源上传。内容仅私密库页面可见：

  • 不进入共享库，不参与公开接口 / 画廊 / 轮播 / Inline 搜图。
  • 仅 vvip 密钥可访问。

勾选后支持批量操作：移入共享库（转为公开内容）、复制链接、批量删除。

入口：也可在「Tele 文件」页勾选文件点「转入私密库」，或「加入共享库」弹窗里选「加入私密库」。

10快速打标

给尚未分类的文件快速补标签的高效工具，是全系统最常用的日常操作。

队列 = Tele 文件库中未入共享库/私密库的全部文件。界面为「中间大图 + 左右各两张半显预览」，鼠标键盘可连续操作：

  • 点标签：给当前文件打上对应标签。
  • 已打标 · 下一张：确认并跳到下一张。
  • 跳过：不处理当前文件（从队列移除）。
  • 转入私密库：当前文件复制到私密库。

下方可给当前文件移除已有标签、点候选标签打标，或添加自定义标签（新增标签会进入候选列表供后续复用）。

自动入共享库：虚线边框的标签是「自动入共享库」标签。文件一旦被打上这类标签，就自动转入共享库，无需手动操作。

11标签库

标签是内容的组织核心，这里统一维护。

  • 预设标签：上传时一键点选的常用标签，保证命名统一。可添加、移除。
  • 全部已用标签：系统里出现过的所有标签及关联图片数。可把常用标签「加入预设」。
  • ⚡ 自动入共享库：给标签开启后，文件被打上该标签即自动进入共享库（快速打标页对应虚线标签）。

12接口生成

可视化生成公开 JSON 接口 URL，复制即可对接第三方。

点选条件自动拼出接口地址：

  • API 密钥：选择「密钥」页生成好的密钥。
  • 文件类型 / 数量 / 模式：模式支持共享库列表、随机取图、上传文件。
  • 关键词 / 标签筛选：进一步收窄返回内容（多标签 = 命中任意一个即可）。

生成后可直接复制、打开测试，或「生成文档」得到接口调用示例。

13密钥管理

第三方程序访问公开接口的凭证与保护。

API 密钥管理

生成密钥时填写用途说明、到期日期（留空 = 永久）、密钥级别。密钥级别决定可获取内容级别（级别对等，见第 2 节）。密钥列表可复制、停用/启用、删除、改级别与有效期。

密钥典型用法：

GET /api/v1/files?api_key=密钥&tags=风景,美女&type=photo&limit=20
GET /api/v1/random?api_key=密钥&tags=风景&count=1
GET /gallery?api_key=密钥
POST /api/v1/upload?api_key=密钥&pool=1&tags=风景&title=标题&level=pt

公开接口限流

设置每分钟每个密钥最多请求数，防止密钥被滥用打爆 Worker 免费额度。超过限制返回 429；关闭限流则所有密钥不限流。

14密钥用户

每个 API 密钥的使用者统计：哪个密钥被哪个 Telegram 用户调用了多少次、最近活跃时间。可用于追踪密钥使用情况。

15兑换码

为用户提供一次性使用的密钥兑换码。

生成兑换码后，用户在 Telegram 机器人中输入兑换码即可激活对应密钥。支持生成/查看/删除兑换码。

16调用日志

公开 API 的调用记录与统计。

  • 调用日志：按时间倒序展示 API 请求记录，包含密钥、接口、状态码、耗时。
  • 调用统计：按密钥维度汇总调用次数，可筛选时间范围。

17轮播展示

控制 /show 展示页（共享库大屏展示）。

  • 基础：展示页开关、自动切换秒数、每次拉取数量、类型、标签筛选、排序（随机 / ID 倒序）。
  • 节目表：每个节目自带图片规则（固定图片 / 每日随机换图），支持按标签/类型/来源过滤 + 周期选择；可勾选「自动换节目」到点自动加载。
  • 显示项：标题 / 标签 / 序号开关。
  • 统计代码：注入百度统计 / Google Analytics 等脚本到展示页底部。

保存后点「打开展示页」预览效果。

18机器人命令

集中管理机器人的命令：启用/停用、自定义回复内容、配置菜单按钮。

内置命令与自定义命令统一在这里维护：

  • 停用的命令（含内置）机器人在群里直接拒绝。
  • 自定义命令可设置触发命令、回复内容、菜单按钮、是否启用。
  • 菜单按钮支持内置操作（retry_all / retry_recent / unsaved_count / count / stats / health / help / pending）或直接回复文本（text:xxx）。

机器人内置命令一览（见第 19 节「Bot API」附近的机器人使用说明）。

19Bot API

后台直接调用 Telegram Bot API 的调试面板，以及输入栏快捷回复键盘配置。

Bot API 测试

选择请求方法（发送 / 查询 / 管理 / Inline 搜图），填写 JSON 参数后发送。两种模式：

  • Worker 代理：经 /bot/<method> 走 worker 内置代理，无需填 Token。
  • 官方 API：填 Bot Token 直连 api.telegram.org（Token 仅存浏览器本地）。

常用场景：sendMediaGroup 发相册、answerInlineQuery 测试 Inline 搜图、pinChatMessage 置顶、getWebhookInfo 查 webhook。

快捷回复键盘

输入栏下方的纯文本按钮，点按钮等价于发送对应文字。配置按钮文字、启用开关后保存；点「广播到全部聊天」可推送到所有私聊。用户 /start 时自动下发。

机器人内置命令

命令作用
/start欢迎语 + 下发快捷回复键盘
/help命令帮助
/count查询现有数量
/pending查询未转存数量
/retry继续完成未转存入库（数字菜单选择批 8/20/全部）

Inline 全局搜图

在任意聊天输入 @机器人 关键词，从共享库全局搜索（标题/标签/URL 模糊匹配），点结果即发图。无结果时自动引导去后台添加。

点按钮 = 发消息：快捷键盘的按钮是纯文本按钮，点按等价于输入对应文字。

20链接解析

/jx 页面：粘贴短链或分享链接，自动解析出最终跳转地址。

支持 xhslink.cn、tieba.baidu.com 等短链重定向。解析后可复制直链或跳转到网页图片直传。

21网页图片直传

/scrape 页面：粘贴任意网页链接，自动抓取页面图片，勾选后直传入库。

基本流程

  1. 输入链接：粘贴网页 URL（支持整段分享文案，系统自动提取其中的链接）。点「拾取图片」。
  2. 勾选图片：页面提取的图片以网格展示，支持全选/全不选/只选前 20 张。
  3. 设置标题与标签：页面标题自动填充，可手动修改；标签用于分类。
  4. 直传：勾选图片后点「直传选中到 Tele 库」，图片经 Telegram 上传群入库。

高级功能

  • 云端规则组：按域名自动匹配不同的忽略规则（关键词/格式/大小限制），规则组存入云端 D1，同一 API Key 在任何浏览器/设备打开共享同一套。新建/修改后 1.2 秒自动同步。
  • 站点 Cookie：对需要登录的站点（如小红书），粘贴 Cookie 后图片下载会携带 Cookie，绕过反爬拦截。Cookie 按域名分站保存在本机浏览器，不上传服务器。
  • 同图去重：http:// 与 https:// 同图只留一条候选，避免重复抓取。
  • 图片直链批量导入：直接粘贴多条图片直链（每行一条），跳过页面解析直接进入候选。
  • 失败重试：直传失败的条目可「一键重试」或「失败项加入候选」重新勾选。
  • 断点续传：关闭页面再打开，未完成的任务自动恢复，可点「续传」继续。
403 下载兜底：系统会按「浏览器 UA + 图床 Referer」→「TG UA」→「纯浏览器 UA」多级重试，自动应对小红书、微博等站点的防盗链。

22R2 文件

直接浏览 R2 存储桶中的文件，支持层级目录浏览、删除、清理孤儿对象。

  • 目录浏览：按文件夹层级查看 R2 中所有对象，支持分页。
  • 对象详情：查看文件名、大小、上传时间、Content-Type。
  • 删除：直接删除 R2 对象（同时需清理 D1 记录，否则成为孤儿）。
  • 孤儿清理：列出 D1 中无引用的 R2 对象，核对后批量清理。

23运维工具

数据安全、告警、通知与运行模式，全部在「运维」标签页。

D1 数据备份

「立即备份到 R2」把数据库快照存到 R2 的 backups/ 目录，自动保留最近 20 份；或「导出并下载」直接拉到本地。可查看备份列表、删除旧备份。建议定期备份。

转存失败告警

转存失败时 bot 发消息提醒你（5 分钟最多 1 条防刷屏）。填入你的 Telegram 用户 ID 并保存，可发送测试。首次使用：先给 bot 发一条消息，再用 @userinfobot 查出自己的 ID。

事件 Webhook 通知

入库 / 删除 / 转存失败时 POST JSON 到外部 URL，供第三方系统实时联动。可勾选触发事件（空 = 全部）。载荷格式：{"event":"file_imported","ts":"...","data":{...}}。发送失败静默跳过。

转存模式

  • 转存到 R2：占存储，直链稳定（推荐默认）。
  • 代理模式：新文件不占 R2，直链由 worker 实时从 Telegram 拉取（仅 ≤20MB，视频/大文件仍转存 R2）。只影响开关后的新文件。
  • 前端仅用代理链接：API display_url / 复制链接一律给 /file/tg/<id> 代理链接，不再给 R2 直链。

用户上传配置

绑定 Telegram 群组用于 TG 直传（sendDocument 入库，不占 R2）和 TG 文件转存。配置上传群组 ID。

共享库图片池

设置共享库图片池的默认行为：来源回退（R2 存储降级策略）、预设标签等。

AI 管理助手

开启后，群里普通文本消息（非命令、非文件）交给大模型处理，可问统计、搜索文件、触发重试转存。配置 OpenAI 兼容的 API Base / 模型 / Key / 系统提示词，可向指定 chat 发送测试消息验证 Key 可用。

说明：AI 仅在纯文本且呈提问/请求意图时触发，纯媒体消息一律不触发，避免群内刷图反复调 AI 导致 429 限流。

用户配额管理

按用户维度设置上传配额：每个用户可上传的最大文件数/大小。超出配额的上传请求会被拒绝。

用户文件管理

查看每个用户上传的文件列表，支持按用户筛选、删除、打标签等操作。

R2 套餐

选择免费版（10GB 存储 + 100 万 A 类 + 1000 万 B 类 / 月）或付费版（不限按量计费），用于概览页配额与超限提醒。A 类 = 写入（上传/转存），B 类 = 读取（访问直链）。

25部署与版本

代码如何上线，版本号如何变化。

自动部署

推送 main 分支即触发 GitHub Actions：语法检查 → wrangler 部署 Worker → 写入 Secrets（TG_BOT_TOKEN / API_KEY / CF_API_TOKEN）→ 二次部署 → 自动注入后台版本号 → 上传 admin.html、admin-guide.html、scrape.html、user.html、user-manage.html、jx.html 等到 R2。

版本号

  • 后台版本号：部署时由脚本自动注入为 v1.0.<GitHub run 号>，显示在后台右上角，每次部署自动递增，无需手动改。
  • Worker 代码版本：/health 与 /stats 返回的 version 字段，需在 worker.js 中手动修改。

验证部署

curl https://<worker域名>/health
# {"ok":true,"time":"...","version":"v7"}

打开后台确认右上角版本号已变为新的 v1.0.<run#>，即可确认本次部署生效。

重要：后台 admin.html、admin-guide.html、scrape.html 等静态页均从 R2 读取。部署工作流会自动上传最新版；若本地手改过这些文件，必须 commit + push 才会随部署更新。
