# 内容分级与私密库

访问控制核心：哪个 API 密钥能看到什么内容。定义在 `src/core.js`。

## 1. 四级

| 级别 | 语义 | 排序 | 徽章 |
|---|---|---|---|
| `pt` | 默认基础 | 最低 | 灰 |
| `vip` | 会员 | 低 | 蓝 |
| `svip` | 超级会员 | 高 | 紫 |
| `vvip` | 最高（含私密） | 最高 | 金 |

- `LEVEL_RANK` / `LEVEL_ORDER`
- `sanitizeLevel(lv)`：非法回落 `pt`
- `levelFilter(keyLevel)`：SQL 片段。支持 `"pt,vip"` 与 `"*"`（不过滤）

## 2. 对等访问

密钥级别 `L` 可见 `level <= L` 的公共内容。`vvip` 额外可见 `is_private=1`。非 vvip 查询追加 `is_private=0`。过滤在 SQL 层完成。

## 3. 私密库

- `is_private = 1` 且固定 `level = 'vvip'`
- 与共享库同一张表 `random_pool`，靠标记隔离
- 管理入口 `/admin/api/private-pool`；从 Telegram 导入级别固定 vvip
- 展示页 `/show/data`、节目换图只取 `level='pt' AND is_private=0`

| 维度 | 高等级公共 | 私密 |
|---|---|---|
| 标记 | `is_private=0`，level 可变 | `is_private=1` + vvip |
| 展示页 | 仅 pt | 永不 |
| 可见密钥 | 级别足够 | 仅 vvip |
| 管理 | `/admin/api/pool` | `/admin/api/private-pool` |

## 4. 落位

| 表 | 列 | 默认 |
|---|---|---|
| `files` | `level` / `is_private` | `pt` / `0` |
| `random_pool` | 同上 | 同上 |
| `api_keys` | `level` | `pt` |

存量未分级按 `pt` 兼容。

## 5. 密钥

后台「密钥」tab：级别、`scopes`（默认 `files:read`，上传需 `files:write` 或 `upload`）、`expires_at`、`key_pass`、`username`。非 vvip 即使请求高级内容也会被 SQL 截断。
