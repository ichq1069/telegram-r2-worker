# 共享库与私密库

后台「共享库」「私密库」两个 tab。表都是 `random_pool`。

## 共享库

- 路由保持 `/admin/api/pool`（UI 更名不改 API）
- 供 `/show`、节目组、`/api/v1/random`
- 来源：本地上传、Telegram、页面导入、Postimages、`upload-tg`
- 支持文件夹（`folders` 表 + `/admin/api/folders` + `/admin/api/pool/move`）
- 命中「自动入共享库」标签的 Tele 文件会自动转入

## 私密库

- `random_pool` 中 `is_private=1` 的行
- 仅 vvip 密钥可见，不进展示页
- `/admin/api/private-pool`、`/admin/api/private-pool/from-tg`

## 区别

| 维度 | 共享库 | 私密库 |
|---|---|---|
| 标记 | `is_private=0` | `is_private=1` + `level='vvip'` |
| 展示页 | 仅 pt 公共 | 永不 |
| 随机接口 | 按密钥级别 | 仅 vvip |
| 可改级别 | 是 | 固定 vvip |

常规公开内容进共享库并设 level；敏感内容进私密库。不要把付费内容设成 `pt` 再指望上轮播。
