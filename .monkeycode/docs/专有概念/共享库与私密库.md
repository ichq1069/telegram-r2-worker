# 共享库与私密库

系统提供两个图片/资源库:共享库(shared pool)与私密库(private pool)。管理后台对应「随机库」与「私密库」两个 tab。

## 1. 共享库(Shared Pool)

- 数据表:`random_pool`(UI 曾称「共享库」,表名/路由保持 `random_pool` / `/admin/api/pool` 不变)
- 用途:供公开轮播页 `/show`、节目组换图、`/api/v1/random` 随机接口使用
- 内容可见性:默认 `level='pt' AND is_private=0` 的内容会出现在展示页与随机接口;高级别内容按密钥级别过滤
- 来源:`/admin/api/pool/upload`(本地上传)、`/admin/api/pool/from-tg`(Telegram 文件)、`/admin/api/pool/import-page`(从展示页导入)、Postimages 批量上传

管理能力(`/admin/api/pool/*`):

| 操作 | 端点 |
|---|---|
| 列表(分页/筛选) | GET `/admin/api/pool` |
| 新增/删除 | POST/DELETE `/admin/api/pool` |
| 批量设置级别 | POST `/admin/api/pool/batch` |
| 批量删除 | POST `/admin/api/pool/batch-delete` |
| 启用/停用 | POST `/admin/api/pool/toggle` |
| 标签设置 | POST `/admin/api/pool/tags` |
| 本地上传 | POST `/admin/api/pool/upload` |
| Telegram 导入 | POST `/admin/api/pool/from-tg` |

## 2. 私密库(Private Pool)

- 数据表:`random_pool` 中 `is_private=1` 的行(无独立表,靠标记隔离)
- 用途:存放「等同 vvip」的高敏内容,仅 vvip 密钥可见,不进入展示页/轮播/共享列表
- 管理:`/admin/api/private-pool`(列表)、`/admin/api/private-pool/from-tg`(从 Telegram 导入,级别固定 vvip)
- 隔离保证:非 vvip 密钥的所有查询都会追加 `is_private=0` 条件,SQL 层保证私密内容不被低级别请求取到

## 3. 两者区别

| 维度 | 共享库 | 私密库 |
|---|---|---|
| 标记 | `is_private=0` | `is_private=1` + `level='vvip'` |
| 进展示页/轮播 | 仅 `pt` 公共条目 | 永不 |
| 随机接口 | 按密钥级别过滤后可见 | 仅 vvip 密钥可见 |
| 后台 tab | 随机库 | 私密库 |
| 可设置级别 | 是(pt/vip/svip/vvip) | 固定 vvip |

## 4. 相关术语沿革

「共享库」为既有 UI 用语的更名结果。为兼容外部调用,**仅改 UI 文案,保留 API 路径与表名**:表仍为 `random_pool`,路由仍为 `/admin/api/pool`,避免破坏既有调用方。更名涉及 `admin.html` 全局文案与 `worker.js` 用户可见提示(错误提示/加载占位)。

## 5. 使用建议

- 常规公开内容 → 共享库,`level` 按内容价值设置
- 敏感/付费高端内容 → 私密库,由 vvip 密钥对接
- 展示页与节目换图只消费 `pt` 公共条目,勿把付费内容设成 `pt` 期望上轮播
