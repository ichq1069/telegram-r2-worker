# 网页抓取与中转

后台「网页拾取」tab + `/scrape` 页。Worker 256MB，大图下载易 OOM，优先交给外部 relay。

## 1. 流程

1. `POST /admin/api/scrape/analyze` 抽页面图片 URL
2. `grab_one` / `grab` 抓取
3. `original_url` 去重（唯一索引）
4. 忽略词 / 必带词 / 扩展名 / 大小过滤
5. **relay 优先**：`grabViaRelay` → 中转下载并 `sendPhoto` 到上传群 → Worker 只写元数据
6. 直链白名单：把 URL 交给 Telegram，失败再 Worker 代理
7. 非直链：`resolvePostimgOriginal` 后 Worker 下载再 `tgProxySave`

`vvip` 级别直接进私密库。可配上传目标群 `/admin/api/settings/upload-group`。

## 2. Relay

Python aiohttp（`relay/relay.py`）。`POST /relay/grab`。环境变量 `PORT`（默认 18088）、`API_KEY`。单文件 50MB，并发 10。

Worker：`RELAY_URL` / `RELAY_KEY`。含历史明文 IP `84.247.129.220` 的 URL 会被改写为 `https://botzzxz.wo58.cn`。健康检查 `/admin/api/scrape/relay-health`。

规则组：`/admin/api/scrape/rule-groups`，PicWall 发现页可触发同一套采集。
