# 群资源编号（group_ref）

格式 `<批次ID>-<序号>`，如 `440-001`。实现：`src/batch.js`。

## 规则

- 批内第 1 条以「下一条预计 files.id」为批次基准，之后递增
- 距上一条超过 5 分钟新批次（`TG_REF_GAP_MS = 300000`）
- 同一 chat 约 3 秒内消息可预分配后合并回执（`scheduleBatchRef` / `refreshGroupReceipt`）
- 用户可用 `#开始` / `#结束` 手动划批次（`startManualBatch` / `finalizeManualBatch`）

编号写入 `files.group_ref` 和 Bot 回复。用户对照回复可发现缺号。不参与访问控制。

并发/乱序下序号可能不连续，不要当业务主键。用户撤销媒体时 `handleDeletedMsg` 软删并清理回执。
