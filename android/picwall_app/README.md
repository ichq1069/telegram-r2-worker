# 图墙 (PicWall)

Android 客户端，连接 Telegram R2 Worker 服务端，提供采集、浏览、上传、管理一体化体验。

## 功能概览

| 模块 | 功能 |
|------|------|
| 发现 | 采集配置管理（Telegram/Reddit/Bilibili/微博）、触发采集、浏览采集结果 |
| 画廊 | 已入库媒体瀑布流浏览、收藏、详情查看（图片+视频）、本地历史 |
| 上传 | 本地相册选择/拍照/URL 上传、WiFi-only 开关、上传队列管理 |
| 相册同步 | 增量扫描相册变更、后台自动同步、同步筛选（类型/大小/格式） |
| 管理 | 统计面板、回收站、孤立资源、存储管理（仅 admin 角色） |
| 设置 | 主题切换、服务器配置、缓存管理、应用锁、调试模式 |
| 应用锁 | 3×3 图案锁 + 生物识别（指纹），冷启动/切后台拦截 |

## 安装

### 方式一：下载 APK

从 GitHub Releases 下载最新 `app-debug.apk`，安装即可。

### 方式二：自行构建

```bash
cd android/picwall_app

# 获取依赖
flutter pub get

# 构建 debug APK
flutter build apk --debug
```

产出路径：`build/app/outputs/flutter-apk/app-debug.apk`

> **注意**：首次构建会自动执行 `flutter create .` 初始化原生 Android 工程，会覆盖 `AndroidManifest.xml`。权限、前台服务、应用名等由 CI workflow 自动注入，本地构建需手动配置。

## 配置

### 服务器连接

首次启动进入引导页，输入服务器地址（如 `https://worker.example.com`）和管理员 token。

普通用户也可通过设置页修改服务器地址。

### 管理员角色

拥有管理员权限的账户可以：
- 访问「管理」Tab（统计、回收站、存储管理）
- 触发采集任务
- 管理采集规则组

进入管理页面：我的 → 连续点击版本号 5 次。

### 应用锁

设置 → 应用锁 → 开启，绘制 3×3 图案密码。支持指纹解锁。

应用锁在以下场景生效：
- 冷启动（杀进程后重新打开）
- 从后台切回前台（默认 30 秒后触发，可调整）

## 常见问题

### Q：服务器连接失败？

1. 确认服务器地址正确，以 `http://` 或 `https://` 开头
2. 确认网络可达（手机和服务器在同一网络或服务器有公网地址）
3. 确认 token 有效（管理员在服务端日志中查看）

### Q：图片/视频加载不出来？

1. 检查网络连接
2. 尝试清除缓存（设置 → 缓存管理 → 清除全部缓存）
3. 确认服务器存储服务正常

### Q：上传失败？

1. 检查文件大小限制（默认 50MB）
2. WiFi-only 模式下确保连接 WiFi
3. 查看调试模式中的错误信息（设置 → 调试模式 → 开启）

### Q：同步不工作？

1. 确认已授权相册访问权限
2. WiFi-only 模式下确保连接 WiFi
3. 确认后台同步权限（前台服务通知）
4. 尝试手动触发：同步页 → 点击同步按钮

### Q：如何切换管理员/普通用户？

同一 token 决定角色。管理员在服务端配置，普通用户无法自行升级。切换账号：我的 → 退出登录 → 重新输入 token。

### Q：调试模式怎么用？

设置 → 调试模式 → 开启。开启后：
- 页面右上角出现红色错误角标
- 点击角标查看错误详情
- 所有页面的网络/本地库错误都会被捕获并展示

调试模式关闭后错误列表自动清空。
