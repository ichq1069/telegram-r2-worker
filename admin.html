API 密钥管理
第三方程序用此密钥调用公开 JSON 接口，密钥级别决定可获取内容级别（pt<vip<svip<vvip，级别对等，低级别不会输出高级别内容）： GET /api/v1/files?api_key=密钥&tags=风景,美女&type=photo&limit=20 · GET /api/v1/random?api_key=密钥&tags=风景&count=1（随机取图）· GET /gallery?api_key=密钥（画廊瀑布流页）· POST /api/v1/upload?api_key=密钥&pool=1&tags=风景&title=标题&level=pt（multipart 上传文件字段名为 file，落库见下方说明，上限 19MB）
给普通用户开通自助面板：勾选「登录密码 key-pass」填入密码，把 /user 地址 + 密钥 + 密码发给用户，对方即可登录查看该密钥的调用统计并自助生成接口链接。

触发事件：
空事件 = 全部通知。载荷格式：{"event":"file_imported","ts":"...","data":{...}}。发送失败静默跳过，不影响主流程。
转存模式 代理模式：新文件不占用 R2 存储，直链由 worker 实时从 Telegram 拉取（仅 ≤20MB，视频/大文件仍转存 R2）；只影响开关后的新文件
AI 管理助手 开启后，群里普通文本消息（非命令、非文件）交给大模型处理，可问统计、搜索文件、触发重试转存
测试：AI 会给目标 chat 发一条自我介绍消息，用于确认 Key 可用。已保存的 Key 会以掩码形式回显在输入框（不会因重复保存丢失）。
R2 套餐 配额由套餐自动决定（后台不再手动填容量/操作数）；概览页用量与超限提醒依据：免费版 10GB 存储 + 100 万 A 类 + 1000 万 B 类 / 月；付费版不限，按量计费
A 类=写入（上传/转存），B 类=读取（访问直链）。
全局配置 Telethon 脚本每次启动从后台拉取这里的所有配置，机器上不留任何敏感信息，换机/换 VPS 无感
抓取任务 每群一个任务，独立断点 last_id；在任意机器运行 python3 scripts/userbot_pull.py --server <worker地址> --token <ub_token> --task <任务ID> 即开始抓取
