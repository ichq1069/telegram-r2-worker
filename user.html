API 文档 使用 API Key 访问你的图片库

认证方式：所有 API 请求需要携带 X-API-Key 头或 ?api_key= 参数。

可用端点：

  • POST /api/v1/user/upload - 上传图片（multipart/form-data，字段名 files）
  • GET /api/v1/user/files - 获取图片列表（支持 page/page_size/keyword/tags）
  • GET /api/v1/user/files/:id - 获取图片详情
  • DELETE /api/v1/user/files/:id - 删除图片
  • POST /api/v1/user/files/:id/tags - 设置图片标签（JSON body: {tags: "tag1,tag2"}）
  • GET /api/v1/user/random - 随机获取图片（支持 count/tags）
  • GET /api/v1/user/quota - 获取配额信息
