API 访问

认证方式：所有 API 请求需要携带 X-API-Key 头或 ?api_key= 参数。

可用端点：

  • POST /api/v1/upload - 上传图片（multipart/form-data，字段名 file）
  • GET /api/v1/files?pool=1 - 获取文件列表
  • GET /api/v1/random - 随机获取图片

参数说明：

  • tags - 标签，逗号分隔
  • title - 标题

文件名规则：上传时自动添加用户 ID 前缀，格式为 {user_id}_{原文件名}

群组绑定：上传的图片会自动绑定到管理员配置的默认群组 ID
